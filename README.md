# Curriculum Vitae

A lightweight, static portfolio built with **React** and **Vite** that showcases a professional resume in both web and PDF formats.

## Features
- **Responsive UI** – TailwindCSS + React for a clean layout on desktop and mobile.
- **PDF Export** – Generate a downloadable PDF using `@react-pdf/renderer`.
- **Iconography** – Uses Lucide icons to illustrate sections.
- **Modern Stack** – Vite, TypeScript, Vitest, Jest‑DOM for testing.

## Quick Start
```bash
# Install dependencies (once)
npm ci

# Development server with hot‑reload
npm run dev

# Run all unit tests
npm test
```

## Build & Deploy
```bash
# Production build
npm run build

# Preview locally
npm run preview

# Deploy to Firebase Hosting (requires firebase-tools)
npm run deploy
```

## Project Structure
- `src/` – Application source code.
- `public/` – Static assets for the preview bundle.
- `vite.config.ts` – Vite & plugin configuration.
- `tailwind.config.js` – Tailwind CSS config.
